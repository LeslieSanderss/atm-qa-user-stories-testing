# 🧪 ATM System QA Exploratory Testing Project

## 📌 Project Overview
This project demonstrates manual QA testing skills using exploratory testing techniques based on user stories. The application under test is an ATM system.

🔗 Application Under Test:
https://cash-flow-quest-qa.lovable.app/

---

## 🎯 Testing Approach
- Exploratory Testing (no formal test cases initially)
- User Story-based validation
- Boundary & negative testing
- UI & functional verification

---

## 🧾 Modules Tested
- Login
- Withdrawal
- Deposit
- Transfer
- Account Statement

---

## 🐞 Key Testing Focus
- Input validation (empty fields, special characters)
- Boundary values (min/max limits)
- PIN security validation
- Transaction accuracy
- UI behavior consistency
