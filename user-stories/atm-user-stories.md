# 🧾 ATM System User Stories

## 🔐 Login
As a user, I want to log into my ATM account so that I can access my banking features securely.

### Acceptance Criteria:
- User must enter valid card number
- User must enter 4-digit PIN
- Invalid credentials should show error message

---

## 💸 Withdrawal
As a user, I want to withdraw money so I can access cash when needed.

### Acceptance Criteria:
- User cannot withdraw more than balance
- User must enter valid numeric amount
- System should update balance after withdrawal

---

## 💰 Deposit
As a user, I want to deposit money into my account so my balance increases.

---

## 🔄 Transfer
As a user, I want to transfer money to another account securely.

---

## 📄 Statement
As a user, I want to view my transaction history so I can track activity.
